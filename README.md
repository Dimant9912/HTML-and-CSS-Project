Ένα σύγχρονο και responsive web project κατασκευασμένο αποκλειστικά με καθαρή **HTML5** και **CSS3**. Το project αναδεικνύει τις βασικές αρχές της δομημένης ανάπτυξης ιστοσελίδων, τη χρήση semantic elements και τη δημιουργία ευέλικτων layouts .


---

##  Βασικά Χαρακτηριστικά -Features

* **Semantic HTML5 Markup:** Καθαρή και προσβάσιμη δομή χρησιμοποιώντας σωστά HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* **Modern CSS Styling:** Χρήση σύγχρονων τεχνικών διαμόρφωσης για καθαρό UI/UX.
* **Responsive Layout:** Πλήρης προσαρμοστικότητα σε διαφορετικά μεγέθη οθονών (Desktop, Tablet, Mobile) με τη χρήση Media Queries.
* **Flexbox & Grid Layouts:** Αξιοποίηση Flexbox και CSS Grid για σωστή ευθυγράμμιση και οργάνωση των στοιχείων.
* **Cross-Browser Compatibility:** Δοκιμασμένο για σωστή εμφάνιση σε όλους τους σύγχρονους browsers (Chrome, Firefox, Edge, Safari).

---

##  Τεχνολογίες που χρησιμοποιήθηκαν (Tech Stack)

* **HTML5:** Δομή και περιεχόμενο.
* **CSS3:** Custom styling, animations και responsive layout rules.
* **Git & GitHub:** Version control και φιλοξενία του project.
